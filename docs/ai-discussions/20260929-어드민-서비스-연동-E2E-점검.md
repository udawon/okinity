# 어드민 ↔ 서비스 사이트 연동 적대적 E2E 점검 (2026-09-29)

## 1. 현황 분석

### 점검 방법
- **운영 DB 쓰기 0건.** 로컬 `.env.local`이 운영 Supabase를 가리키기 때문에 가짜 Supabase 샌드박스를 따로 만들어 시험했다.
  - 가짜 서버: PostgREST·Storage 중 앱이 실제로 쓰는 부분만 흉내 낸다.
  - 데이터: 운영 `site_content` 53개 키를 읽기 전용으로 복사하고, 가짜 예약 3건을 넣었다.
  - 앱: 운영 모드 빌드(`next build && next start`)로 띄웠다. 캐시 문제까지 드러나게 하기 위해서다.
  - 메일: 발송 키를 비워 한 통도 나가지 않게 했다.
- **운영 사이트 읽기 전용 순회:** 20개 경로 × ko/en/ja × 휴대폰(390×844)/PC(1440×900) = 126개 페이지를 점검했다.
  - 항목: 상태코드, 콘솔 오류, 깨진 이미지, 가로 넘침, EN/JA 페이지의 한국어 노출, 내부 링크 125개.
- **코드 정적 점검:** 보조 에이전트 2명이 투어·예약 영역과 홈·블로그·공지·소개 영역을 나눠 찾았다. 후보 약 40건은 런타임이나 운영 데이터로 한 번 더 확인했다.
- **시간대 시험:** Asia/Seoul, UTC, America/Los_Angeles 세 곳에서 확인했다.

### 이상 없음으로 확인된 부분
- 저장 후 캐시: 공개 페이지는 모두 `force-dynamic`이고 저장 액션은 모두 `revalidatePath('/', 'layout')`를 호출한다. 오래된 화면이 남지 않는다.
- XSS: 어드민 입력을 `dangerouslySetInnerHTML`로 넣는 곳이 없다.
- 내부 링크 125개 모두 정상.
- 운영 예약 5건의 상품명이 모두 정상적으로 해석된다(구버전 상품명 없음).
- 옵션을 고른 예약: 투어 → 예약 폼 → 어드민 대시보드까지 옵션명·인원·날짜·시간이 정확히 전달된다.

### C. 잠재·낮음 (현재 데이터에서는 발생하지 않음)
- 요금 구간에서 "모든 클래스" 구간이 럭셔리 요금을 덮어씀.
- 옵션명이 약 70자를 넘으면 해당 옵션 예약이 모두 400.
- 사진 목록에 영상 URL을 넣으면 깨짐.
- 직접 입력한 외부 URL이 CSP에 막힘.
- HEIC 업로드.
- 파싱 실패한 항목이 다음 저장 때 삭제됨.
- 새 글 기본 날짜가 UTC 기준(JST 0~9시에 전날로 찍힘).
- 공지가 한국어 전용.
- 옵션 최소 인원을 서버에서 검증하지 않음.

## 3. 해결 방안

### 근본 원인 1 — 언어별 저장본이 "통째 복사"라서 A1·A5·A11이 생김
- **옵션 1: 필드 단위로 한국어 폴백 + 언어 공통 필드 확대**
  - 공개 여부와 숫자 요금은 한국어 저장본만 읽는다.
  - 번역본에서 비어 있는 칸은 한국어로 채운다.
  - 장점: 구조적으로 재발을 막는다.
  - 단점: 번역본에 "옛 문구"가 남아 있으면 여전히 틀린 문구가 보인다(A1의 가격 글이 이 경우).
- **옵션 2: 어드민에 "번역이 한국어보다 오래됨" 경고**
  - 투어 목록·대시보드에서 ko `updated_at`이 en/ja보다 늦으면 표시한다.
  - 장점: 가격 글처럼 사람이 고쳐야 하는 부분을 운영자가 알 수 있다.
  - 단점: 경고일 뿐 자동으로 막지 못한다.
- **권장: 옵션 1 + 옵션 2를 함께 적용하고, A1 가격 글은 즉시 콘텐츠를 수정한다.**

### 근본 원인 2 — 시간대: A6·A10
- "오늘"과 날짜 표시를 Asia/Tokyo(영업지 기준)로 고정한다. 서버와 브라우저가 같은 값을 계산한다.

### 근본 원인 3 — 줄바꿈 규칙: A2·A9
- `break-keep`(keep-all)을 일본어에서는 풀고(`:lang(ja)`), 본문 영역에 `overflow-wrap: anywhere`를 추가한다.

## 4. 트레이드오프
- **필드 폴백의 부작용:** EN 페이지에서 번역이 없는 칸에 한국어가 섞여 보인다. 그래도 틀린 가격보다는 낫고, 옵션 2의 경고로 번역을 유도한다.
- **옵션 최대 인원(A7):** 어드민에 칸이 하나 늘어난다. 대안은 "1인 단독" 이름을 보고 추측하는 것인데 취약하므로 권장하지 않는다.
- **홈 예약 폼 옵션(A4):** 홈 페이지가 투어 옵션 데이터를 추가로 읽는다. `/reserve`와 같은 로더를 공용으로 쓰면 비용이 작다.
