# GEO 1단계 — 회사 정보 일관성 (2026-11-18)

GEO(생성형 AI가 답변 근거로 사이트를 쓰게 만드는 작업) 점검 결과 1번 문제 "페이지마다 회사 정보가 다름"을
원님 인터뷰로 사실을 확정한 뒤 고친다. 기준: zestcompany GEO 시리즈 1편 체크리스트(정보 일관성·구조화 데이터 정합성).

## 1. 현황 분석 (운영 실측)

| 항목 | 위치 | 현재 |
|---|---|---|
| 대표 | 전 페이지 하단(`site.config.ts`) | `代表 比嘉海斗` |
| 대표 | 소개(어드민 `about`) | `허 범영 … 오키니티 대표` |
| 경력 | 소개 intro(어드민) | `11년 경력의 한국인 대표강사` |
| 경력 | 홈 PADI 카드(어드민 `home_tour_copy`) | `10년차 다이버의 PADI 커리큘럼` |
| 보험·픽업·인원 | EN/JA 홈(`messages/*.json` 고정 번역) | 전 게스트 보험 완비 · 주요 숙소 무료 픽업 · 한 팀 최대 6명 |

투어·소개는 2026-09-29부터 한국어 저장 → EN/JA 자동 번역(lib/content-sync)이지만 홈은 대상이 아니었다.

## 2. 문제 정의 (원님 확인 사실)

- 比嘉海斗 = 허범영(같은 사람, 일본 이름). AI 가 "대표 2명"으로 읽을 수 있다.
- 경력 2015년 시작 → 표기는 "10년 이상 경력"으로 통일(해가 바뀌어도 참).
- 픽업: 요구가 많은 고객 때문에 전면 노출하지 않는다. 무료 픽업 문구 삭제, 상담 문구로 통일.
- 보험(실제 다이빙+스노클링): 사이트에 적지 않는다(질문 시 대표가 직접 답변).
- 스노클링: 가이드 1명당 최대 8명, 참가 인원 제한 없음(프라이빗 포함). "한 팀 최대 6명"은 사실 아님.
- 체험다이빙 강사 1:2, 숨긴 히어로 배지(PADI 공인 다이브센터·10년 무사고)는 사실.

## 3. 해결 방안

### A. EN/JA 홈 정합 방식
- A1. `messages/*.json` 고정 번역만 현재 한국어에 맞춰 교체 — 작업 작음. 다음 한국어 수정 때 다시 어긋남(원인 그대로).
- A2. 홈 문구(Hero·투어 카드·신뢰 영역)도 한국어 저장 → EN/JA 자동 번역 — 기존 content-sync 재사용, 재발 없음.

### B. 어드민 콘텐츠 반영
- B1. 원님이 어드민 화면 8곳 수작업.
- B2. Claude 가 운영 DB 에 직접 반영(백업·전후 승인) → 원님은 어드민 "번역 맞추기"만.

## 4. 트레이드오프

| | A1 | A2 |
|---|---|---|
| 작업량 | 작음 | 중간(동기화 대상 3종 추가·홈 조회 변경) |
| 재발 | 한국어 수정 때마다 | 없음 |
| 비용 | 없음 | 홈 저장 시 번역 API 소량 |

B2 는 DB 직접 쓰기 위험이 있으나 전체 백업 + 전후 문구 승인 + 키 단위 쓰기로 통제한다.

## 5. 권장 사항 (원님 결정)

A2 + B2. 보험은 비노출, 픽업은 상담 문구, 이름은 언어별 병기.

## 6. 구현 계획

### 코드 (PR)
1. `src/lib/content-sync.ts` — `textEntries` 가 `이름{}`(객체의 모든 키) 경로를 지원. `SYNC_PATHS` 에
   `homeHero`·`homeTourCopy`·`homeAssurances` 추가. 테스트 먼저(`content-sync.test.ts`).
2. `src/lib/content-sync-server.ts` — `syncItems()` 에 홈 3종 추가(어드민 "번역 맞추기" 대상).
3. `src/app/admin/content-actions.ts` — `saveContent` 가 번역 대상 키면 저장 뒤 자동 번역(갤러리와 동일).
   Hero·투어 카드·신뢰 폼은 번역 결과 메시지 표시(`showSaved`).
4. `src/lib/home-content.ts` — 로케일별 홈 문구 문서 선택 헬퍼(ko=기본 키, EN/JA=`키:locale` 만, 한국어 폴백 없음).
   `src/app/[locale]/page.tsx` 가 EN/JA 에도 번역본을 적용(배경 미디어·숨김 여부는 계속 한국어 저장본).
5. 하단 대표 표기 — `site.config.ts` 에 언어별 표기·이름 목록, `Footer` 가 로케일별 출력.
6. 홈 JSON-LD — 대표 Person(언어별 이름 + alternateName 전부, worksFor → 사업체 @id).
7. `src/lib/translate.ts` 용어 — `허범영 (比嘉海斗)` → EN `Beomyoung Heo (Higa Kaito)`, JA `比嘉海斗（ホ・ボミョン）`.
8. 기본 문구(`messages/*.json` assurance, `ocean-home-data.ts` ASSURANCES)에서 보험·무료 픽업·6명 삭제 —
   현재 어드민 한국어 문구와 같은 내용으로.
