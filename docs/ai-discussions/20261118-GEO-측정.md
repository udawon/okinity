# GEO 3단계 — 측정(유입 경로·AI 문의·크롤러·답변 기준선) (2026-11-18)

기준 글 체크리스트 5·6번("수정 전 기록", "정기 재확인"). 1·2단계 변경의 효과를 보려면 측정이 먼저 필요하다.

## 1. 현황 분석
- 방문 집계(`site_visits`)는 하루 방문자 수만 — 어디서 왔는지 모름. 예약 문의에도 출처 없음.
- AI 크롤러가 실제로 무엇을 읽는지 기록 없음(Vercel 로그는 보관 짧음).
- AI 답변(언급·출처·추천) 기준선 없음.

## 2. 문제 정의
GEO 효과(AI 답변 노출 → 방문 → 문의)를 단계별로 셀 수단이 없다. 매출과 연결되는 건 문의 출처.

## 3. 해결 방안 / 4. 트레이드오프
- 저장: (a) 테이블 칸 추가(SQL 1회, 정확) (b) 콘텐츠 저장소에 합계만(동시 방문 누락·크롤러 불가) → (a)
- 문의 출처: 처음/마지막/둘 다 → 둘 다(처음은 30일 기억)
- 답변 기준선: 수동 월 1회 / 자동 API → 수동(손님이 보는 앱 화면 그대로, 비용 0). 단 원님 40분/월
- 기록 장소: 구글 시트 / 어드민 / 로컬 → 어드민(유입 통계와 한 화면, 개발 큼)

## 5. 권장 사항 (원님 결정)
측정 4종 모두. SQL 1회(docs/supabase-geo-tracking.sql). 질문 10개 고정, 플랫폼 ChatGPT·구글 AI 개요·
네이버 AI 브리핑·Claude. 유입처는 사이트 이름만 저장(개인정보 최소화).

## 6. 구현 계획
1. `src/lib/traffic-source.ts`(순수) — referrer·utm_source·앱 안 브라우저(UA)로 유입처 분류, 라벨, AI 여부.
2. `src/lib/crawlers.ts`(순수) — UA → 크롤러 이름(AI·검색 구분). 미들웨어가 운영에서만 기록(waitUntil, 응답 지연 없음).
3. `src/lib/geo-checks.ts`(순수) — 질문 10개·플랫폼 4개·입력 검증·월별 요약.
4. 방문 비콘 — 유입처를 서버로 보내 `site_visits.source` 에 기록. 처음(30일)/마지막 유입처를 브라우저에 기억.
5. 예약 문의 — 처음·마지막 유입처를 `inquiries.source_first/source_last` 에 저장, 어드민 예약 목록·메일에 표시.
6. 어드민 "AI 노출" 화면 — 유입 경로(30일), AI 유입 문의(90일), 크롤러(30일), 답변 기록 입력·요약.
7. SQL 실행 전 배포돼도 깨지지 않게 — 칸이 없으면(PGRST204/42703) 새 칸 없이 다시 저장, 표가 없으면 화면에 안내.

### 변경 영향
- 예약 문의 저장 경로가 바뀌므로 칸 없음 재시도 테스트 필수(문의 유실 금지).
- 미들웨어: 봇 요청에만 비동기 기록 1회, 사람 방문에는 영향 없음.

## 7. 구현 중 추가 결정·검증 (2026-11-18)
- **마지막 유입 = 마지막 비직접 유입**: ChatGPT로 알고 나중에 즐겨찾기로 와 문의해도 AI 기여가 남도록, 기억이 있을 때 직접 방문은 덮어쓰지 않음(GA 방식). 브라우저 확인 중 발견해 수정.
- **기록 입력**: 날짜·플랫폼 하나 = 질문 10개 한 화면, 한 번 저장(월 4회). 같은 날짜·플랫폼 재저장은 덮어쓰기, 월 집계는 질문별 최신 1건(분모 10 유지). 플랫폼을 바꿔도 입력 중 내용 유지(저장 안 한 플랫폼 ● 표시).
- **SQL 실행 전 배포 안전성**: 운영 DB에 저장 없이 오류 코드 확인 — 칸 없음 PGRST204/42703, 표 없음 PGRST205. 문의는 유입 없이 재저장, 화면은 "SQL 실행 필요" 안내.
- **Supabase 1,000행 제한**: 통계 조회는 페이지 단위로 끝까지 읽음(lib/db-paging).

## 8. 측정의 한계(해석 시 주의)
- 구글 AI 개요·네이버 AI 브리핑에서 누른 클릭은 일반 검색과 referrer 가 같아 **구글·네이버로 합산**된다 → 이 둘은 월 1회 수동 기록으로만 본다.
- ChatGPT 는 답변 링크에 `utm_source=chatgpt.com` 을 붙여 앱에서도 잡히지만, 링크 없이 이름만 보고 검색해 오면 구글·네이버·직접 방문으로 잡힌다.
- 방문자 수는 IP·브라우저 해시 기반 참고 지표(같은 와이파이 합산 등, lib/visit-key).
- 크롤러는 UA 자기 신고 기준(위장 봇 구분 안 함). 행은 하루·봇·주소당 1개라 용량은 월 수 MB 이내 예상.
